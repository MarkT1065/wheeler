About Polygon.io API

Wheeler uses the Polygon.io (Massive) API to automatically fetch market data in the background.

  • Stock Prices: Daily close prices for all tracked symbols
  • Price History: Historical OHLCV bars for charting and analysis
  • Option History: Daily bars for open option contracts
  • Index Data: SPX, NDX, DJI, VIX historical data
  • Dividends: Corporate action data for dividend tracking

The background worker runs continuously using the free tier (5 calls/min, 12s between requests). No manual updates needed.
